https://guymanstuff.github.io/spudarino/

| App | Support | Privacy |
|---|---|---|
| Ohm My! | [ohmmy/](https://guymanstuff.github.io/spudarino/ohmmy/) | [ohmmy/privacy.html](https://guymanstuff.github.io/spudarino/ohmmy/privacy.html) |

Have a question or found a problem with an app?
[Open an issue](https://github.com/guymanstuff/spudarino/issues/new).

## Adding another app

1. Copy the `ohmmy/` folder to a new folder (e.g. `punchlist/`).
2. Replace `icon.png` and update the text in `index.html` and `privacy.html`.
3. Add the app to the list in the top-level `index.html`.
4. Commit and push; GitHub Pages republishes automatically within a minute or two.
